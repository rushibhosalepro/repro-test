# ShopLite

A tiny online shop: browse and search products, add them to a cart, apply a coupon, place an order.

```bash
bun run dev   # http://localhost:3000
```

Pages:

- `/` product list with search
- `/cart` cart, quantity buttons, coupon field, totals, Place Order
- `/orders` your orders

Coupon to try: `SAVE10` (10% off).
